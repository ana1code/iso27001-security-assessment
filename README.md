## 📌 Project Overview

This project presents a practical information security assessment of a fictional SaaS business management platform.

The assessment applies ISO 27001 and ISO 27002 principles to identify cybersecurity risks, evaluate security gaps, map relevant controls and propose security improvements.

The project also includes a simulated security incident to demonstrate the application of an incident response process.

---

## 🏢 Scenario

**CloudGest** is a fictional SaaS company providing an online business management and invoicing platform.

The platform includes:

* Customer and supplier management
* Invoicing and commercial documents
* Sales and purchasing management
* Stock management
* Web applications
* APIs
* Mobile applications
* Cloud-based infrastructure

The platform processes business and customer information, making confidentiality, integrity and availability important security requirements.

---

## 🎯 Project Objectives

The main objectives of this assessment are to:

* Identify relevant cybersecurity risks
* Assess likelihood and business impact
* Map risks to security controls
* Identify security gaps
* Recommend risk mitigation measures
* Prioritize security improvements
* Simulate an incident response process

# 🚨 Incident Response Summary

The simulated incident demonstrates how a security team could respond to a potentially compromised privileged account.

### Detection

Suspicious authentication and API activity is identified.

### Triage

The alert is validated and escalated based on potential impact.

### Investigation

Authentication, API, application and cloud logs are reviewed.

### Containment

Compromised sessions are revoked and credentials are reset.

### Eradication

The potential attack vector is investigated and affected systems are secured.

### Recovery

Systems are validated and returned to normal operation.

### Lessons Learned

Security controls and incident response procedures are reviewed and improved.

# 💡 Key Takeaways

This project demonstrates how information security principles can be translated into practical security decisions.

Rather than treating security controls as isolated requirements, the assessment connects:

**Risk → Control → Gap → Recommendation → Response**

This approach helps organizations continuously improve their security posture while reducing the potential impact of cybersecurity incidents.
