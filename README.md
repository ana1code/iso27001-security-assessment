# 🛡️ ISO 27001/27002 Security Assessment

## 📌 Project Overview

This project presents a practical security assessment of a fictional SaaS business management platform.

The assessment applies ISO 27001 and ISO 27002 principles to identify cybersecurity risks, security gaps and appropriate controls.

The project focuses on how security controls can be applied to a cloud-based platform that processes business and customer information.

---

## 🏢 Scenario

**CloudGest** is a fictional SaaS company that provides an online business management and invoicing platform.

The platform includes:

* Customer and supplier management
* Invoicing and commercial documents
* Sales and purchasing management
* Stock management
* Web application
* API services
* Mobile applications
* Cloud-based infrastructure

Because the platform processes business and customer information, protecting the confidentiality, integrity and availability of information is critical.

---

## 🎯 Assessment Objectives

The main objectives of this assessment are to:

* Identify relevant cybersecurity risks
* Assess potential business impact
* Map risks to security controls
* Identify security gaps
* Recommend appropriate security measures
* Prioritize security improvements
* Define an incident response scenario

---

## 🔎 Assessment Areas

The assessment focuses on:

* Access Control
* Cryptography
* Security Operations
* Communications Security
* Secure Development
* Supplier Security
* Incident Management

---

## 📊 Project Structure

The assessment is divided into the following stages:

1. Scenario Definition
2. Risk Assessment
3. ISO 27001/27002 Security Controls
4. Security Gap Analysis
5. Security Recommendations
6. Incident Response Scenario
